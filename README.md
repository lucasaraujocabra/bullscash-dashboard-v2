# BullsCash · Painel 2.0

Proposta de redesign do painel do gateway BullsCash. Dados de demonstração.

```sh
npm install
npm run dev      # http://localhost:5179
npm run build
npm run deploy   # publica no GitHub Pages
```

Stack: Vite, React 19, Tailwind v4, Geist, Phosphor, Three.js (a esfera do card de saldo).
